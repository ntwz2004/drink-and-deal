# บันทึกสถานะการเล่นด้วย Cloud + ลูกเต๋าใหญ่ขึ้น

## เป้าหมาย
- เปิด Lovable Cloud แล้วบันทึกสถานะการเล่นปัจจุบันไว้ กลับมาเปิดใหม่ก็เล่นต่อได้
- สถานะจะถูกล้างเมื่อกด "เริ่มใหม่" เท่านั้น
- ลูกเต๋า 3D ใหญ่ขึ้น

## สิ่งที่จะทำ

### 1. เปิด Lovable Cloud
สร้าง backend ให้โปรเจกต์ (ฐานข้อมูล) โดยไม่ต้องสมัครบัญชีเพิ่ม

### 2. บันทึกต่ออุปกรณ์ (ไม่ต้องล็อกอิน)
- สร้าง device id แบบสุ่มเก็บในเครื่อง ใช้เป็นกุญแจอ้างอิงแถวข้อมูล
- ตาราง `game_sessions` เก็บ:
  - เกมไพ่: สำรับที่เหลือ, ไพ่ใบล่าสุด, ประวัติการจั่ว, กติกาที่แก้ไข
  - เกมลูกเต๋า: ชื่อผู้เล่น 1-6, ผลลัพธ์ล่าสุด
- บันทึกอัตโนมัติทุกครั้งที่จั่วไพ่ / ทอยเต๋า / แก้ชื่อ-กติกา (debounce สั้น ๆ)
- ตอนเปิดหน้าเว็บ จะโหลดสถานะเดิมกลับมาแสดง
- ปุ่ม "เริ่มใหม่" = ล้างข้อมูลในฐานข้อมูลของอุปกรณ์นั้นและรีเซ็ตหน้าจอ (จุดเดียวที่ล้างข้อมูล)

### 3. ลูกเต๋าใหญ่ขึ้น
- ขยายขนาดลูกเต๋าจาก 120px เป็นประมาณ 170px (responsive: เล็กลงเล็กน้อยบนจอมือถือแคบ)
- ปรับ perspective/เงาให้สมดุลกับขนาดใหม่ และเว้นระยะรอบ ๆ ไม่ให้ชนกับ layout

## รายละเอียดทางเทคนิค
- ตาราง `public.game_sessions` (device_id text unique, card_state jsonb, dice_state jsonb, updated_at)
- ไม่มีการล็อกอิน จึงเปิด policy ให้ anon อ่าน/เขียนได้เฉพาะแถวที่ตรง device_id ที่ส่งมา พร้อม GRANT ให้ anon และ service_role
  - หมายเหตุความปลอดภัย: ข้อมูลเป็นสถานะเกมปาร์ตี้ ไม่ใช่ข้อมูลส่วนตัว ผู้ที่เดา device id ได้ (uuid สุ่ม) เท่านั้นถึงจะเข้าถึงแถวนั้นได้
- hook `useGameSession` กลางสำหรับ load/save/clear ใช้ทั้ง `Index.tsx` และ `DiceGame.tsx`
- `Dice3D.tsx` เปลี่ยน `size` เป็น prop พร้อมค่าเริ่มต้นใหญ่ขึ้น
