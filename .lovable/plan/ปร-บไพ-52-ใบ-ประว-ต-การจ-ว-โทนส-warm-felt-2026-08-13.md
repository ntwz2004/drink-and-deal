# ปรับไพ่ 52 ใบ + ประวัติการจั่ว + โทนสี Warm Felt

## 1. ไพ่ทั้ง 52 ใบให้เหมือนสำรับจริง

วาดใหม่ทั้งหมดด้วยเวกเตอร์ (ไม่ใช้ไฟล์รูปที่อัปโหลด เพราะความละเอียดต่ำเกินไป — ไพ่ใบละ ~54x74px จะเบลอ) โดยอ้างอิงเลย์เอาต์จากรูปที่ให้มา:

- **A–10**: ตัวเลข + ดอกมุมบนซ้าย และมุมล่างขวากลับหัว, จุดดอก (pips) จัดตำแหน่งตามมาตรฐานสำรับจริง ครึ่งล่างกลับหัว
- **A**: ดอกใหญ่กลางใบ
- **J / Q / K**: วาดเป็น court card แบบสองหัวสะท้อนกัน (บนกับล่างกลับหัวตรงกลางแบ่งด้วยเส้นทแยง) มีมงกุฎ/หมวก/ใบหน้า/เสื้อคลุมลายเรขาคณิต สีแดง–ดำ–เหลืองทอง–น้ำเงินแบบไพ่คลาสสิก และเปลี่ยนสีตามดอกไพ่
- ขอบไพ่บาง มุมโค้ง พื้นขาว ตามรูปต้นแบบ
- หลังไพ่ปรับให้เข้าโทนใหม่

## 2. ประวัติการจั่วไพ่

- เก็บลำดับไพ่ที่จั่วไปแล้วในหน้าเกมไพ่
- ปุ่ม "ประวัติ" ที่แถบล่าง เปิด panel (sheet) ขึ้นมา
- ใน panel: รายการไพ่เรียงจากใหม่→เก่า แต่ละแถวแสดงไพ่ใบเล็ก (rank + ดอก สีตามดอก), ลำดับที่, และกติกาของใบนั้น
- ปุ่ม "เริ่มเกมใหม่" ล้างประวัติด้วย

## 3. โทนสี Minimal (Warm Felt)

ปรับ design token ใน `index.css` + `tailwind.config.ts`:

- พื้นหลัง `#12211B` (เขียวโต๊ะไพ่เข้ม), การ์ด/พื้นผิว `#1C2F26`
- ตัวอักษร `#EAE7E1`, accent `#C0392B` (แดงไพ่)
- ตัด neon glow / gradient หลากสีออกทั้งหมด → ใช้เส้นขอบบาง + เงานุ่มแทน
- ปรับหน้า Home, หน้าไพ่, หน้าลูกเต๋า ให้ใช้โทนเดียวกัน
- โลโก้/หัวเรื่อง: เปลี่ยนจาก emoji + ตัวหนาเรืองแสง เป็น wordmark เรียบๆ พร้อมไอคอนเส้น (line icon) แทน emoji บนการ์ดเลือกเกม
- ลูกเต๋า 3D ปรับสีหน้าลูกเต๋าให้เข้าโทน (ขาวนวล จุดเข้ม)

## รายละเอียดทางเทคนิค

- `src/components/CardPips.tsx` — ปรับ layout จุดให้ตรงมาตรฐาน + จุดครึ่งล่างกลับหัว
- `src/components/FaceCard.tsx` — เขียนใหม่เป็น SVG court card สองหัว
- `src/components/PlayingCard.tsx` — ปรับสไตล์ขอบ/เงา/หลังไพ่ให้ minimal
- `src/components/HistoryPanel.tsx` — ใหม่ (ใช้ shadcn Sheet)
- `src/pages/Index.tsx` — state `history`, ปุ่มเปิด panel
- `src/index.css`, `tailwind.config.ts` — โทนสีใหม่
- `src/pages/Home.tsx`, `src/pages/DiceGame.tsx`, `src/components/Dice3D.tsx` — ปรับให้เข้าโทน
- ไม่มี backend ทุกอย่างเป็น state ในหน้า (ประวัติหายเมื่อรีเฟรช)
